# 云服务器部署指南

本文介绍把 Chenji Learning Hub 部署到云服务器（Docker + Nginx）的完整步骤。当前线上服务器 IP：`47.242.176.227`，域名 `chenji.felixfu.xyz`。

## 1. 线上结构

```
客户端浏览器
  → HTTPS (443) 云服务器 Nginx
    → /         前端静态资源（Docker 容器，Nginx 托管）
    → /api/*    反代到后端 FastAPI（Docker 容器）
                后端连接 PostgreSQL / SQLite（Docker volume）
```

## 2. 服务器初始化

```bash
# 安装 Docker（Debian/Ubuntu 示例）
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker "$USER"

# 安装 Git
sudo apt update && sudo apt install -y git
```

## 3. 克隆项目并配置环境变量

```bash
sudo mkdir -p /opt/chenji-learning-hub
sudo chown "$USER":"$USER" /opt/chenji-learning-hub
git clone https://github.com/chenji0421/chenji-learning-hub-fullstack.git /opt/chenji-learning-hub
cd /opt/chenji-learning-hub

# 复制线上环境变量模板并填写真实值
cp .env.server.example .env
```

`.env` 中需要填写的关键项：

| 变量 | 说明 |
|---|---|
| `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET` | GitHub OAuth App 的密钥 |
| `GITHUB_OAUTH_CALLBACK_URL` | `https://chenji.felixfu.xyz/api/auth/github/callback` |
| `ADMIN_GITHUB_LOGIN` | `chenji0421` |
| `AUTH_SECRET` | 随机长字符串：`openssl rand -hex 32` |
| `FRONTEND_URL` | `https://chenji.felixfu.xyz` |
| `VITE_API_URL` | 前端构建时指向的后端地址（同域留空即可，由 nginx 反代 `/api`） |
| `DATABASE_URL` | 默认 `sqlite:////app/data/chenji_hub.db`（Docker volume 持久化） |

## 4. 启动服务

```bash
# 校验 compose 配置
docker compose --env-file .env -f docker-compose.server.yml config --quiet

# 构建并启动
docker compose --env-file .env -f docker-compose.server.yml up -d --build

# 查看状态
docker compose --env-file .env -f docker-compose.server.yml ps
```

- 前端容器监听 `127.0.0.1:18080`（只本机可访问，由宿主 Nginx 反代）。
- 后端只在 Compose 内部网络可达，`/api` 由前端 Nginx 容器反代。

## 5. 配置宿主 Nginx

参考 `deploy/nginx-host-example.conf`，把 `server_name` 改成 `chenji.felixfu.xyz`，`/` 反代到 `127.0.0.1:18080`。

### 添加 HTTPS（推荐）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d chenji.felixfu.xyz
```

Certbot 会自动申请证书并配置跳转。

## 6. DNS

在域名服务商控制台添加 A 记录：

```text
chenji.felixfu.xyz -> 47.242.176.227
```

## 7. GitHub OAuth 回调

GitHub OAuth App 的回调地址必须与线上一致：

```text
Homepage URL:            https://chenji.felixfu.xyz
Authorization callback:  https://chenji.felixfu.xyz/api/auth/github/callback
```

## 8. 更新上线

```bash
cd /opt/chenji-learning-hub
git pull --ff-only
chmod +x scripts/deploy-production.sh
./scripts/deploy-production.sh
```

日常更新通常走 GitHub Actions 自动完成，手动命令用于排查。
