# 服务器运维手册

本文覆盖 Chenji Learning Hub 线上服务器的日常运维操作。线上服务器 IP：`47.242.176.227`，项目目录 `/opt/chenji-learning-hub`。

## 1. SSH 登录

```bash
ssh <deploy_user>@47.242.176.227
```

> 生产服务器建议禁用密码登录，只允许密钥登录（`/etc/ssh/sshd_config` 中 `PasswordAuthentication no`）。

## 2. 查看服务状态

```bash
cd /opt/chenji-learning-hub
docker compose --env-file .env -f docker-compose.server.yml ps
```

期望看到 `backend` 和 `frontend` 两个容器 `Up`（backend 需 healthy）。

## 3. 查看日志

```bash
# 后端日志
docker compose --env-file .env -f docker-compose.server.yml logs -f backend

# 前端 / nginx 日志
docker compose --env-file .env -f docker-compose.server.yml logs -f frontend

# 只取最近 100 行
docker compose --env-file .env -f docker-compose.server.yml logs --tail 100 backend
```

## 4. 更新代码

```bash
cd /opt/chenji-learning-hub
git pull --ff-only
chmod +x scripts/deploy-production.sh
./scripts/deploy-production.sh
```

日常更新通常由 GitHub Actions 自动完成；手动执行用于排查或紧急回滚。

## 5. 重启服务

```bash
cd /opt/chenji-learning-hub
docker compose --env-file .env -f docker-compose.server.yml restart backend
docker compose --env-file .env -f docker-compose.server.yml restart frontend
```

## 6. 宿主 Nginx

- 配置位置：`/etc/nginx/sites-available/`（或安装方式对应的目录），参考 `deploy/nginx-host-example.conf`
- 修改后验证并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

- 查看访问 / 错误日志：

```bash
sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log
```

## 7. HTTPS 证书

- 用 Certbot 申请（Let's Encrypt）：
  ```bash
  sudo certbot --nginx -d chenji.felixfu.xyz
  ```
- 证书快过期时续期（或配置自动续期）：
  ```bash
  sudo certbot renew --dry-run
  ```

## 8. 备份

按 [数据库备份和恢复](./数据库备份和恢复.md) 定期备份数据库。Docker volume 数据也建议定期快照。

## 9. 故障排查速查

| 症状 | 排查方向 |
|---|---|
| 网站打不开 | `docker compose ps` 容器是否在跑；`nginx -t` 配置是否合法 |
| `/api` 返回 502 | 后端容器是否 healthy；nginx 反代地址是否指向 `127.0.0.1:18080` |
| GitHub 登录失败 | OAuth 回调地址是否一致；后端日志里的具体报错 |
| 页面旧版本 | Actions 是否部署成功；浏览器强刷（Ctrl+F5） |
| 磁盘满 | `df -h`；清理旧 Docker 镜像 `docker image prune` |
| 数据库连不上 | `DATABASE_URL` 是否正确；PostgreSQL 服务是否在跑 |

## 10. 危险命令（谨慎执行）

以下命令会**删除数据或停止服务**，执行前务必先备份：

```bash
# 删除容器（保留 volume 数据）
docker compose --env-file .env -f docker-compose.server.yml down

# 删除容器 + volume（⚠️ 数据会丢！）
docker compose --env-file .env -f docker-compose.server.yml down -v

# 删除所有未使用的镜像
docker image prune -a
```
